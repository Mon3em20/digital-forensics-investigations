# Digital Forensics Investigations

## Overview

This repository documents multiple digital forensics investigations involving memory forensics, registry analysis, and malicious network traffic analysis within controlled educational lab environments.

The investigations focused on identifying suspicious processes, credential theft activity, malware-related communications, attacker infrastructure indicators, and forensic artifacts using industry-standard forensic and network analysis tools.

---

# Investigation Areas

## Memory Forensics
- Windows memory analysis
- Running process investigation
- User session analysis
- Hash extraction
- Registry artifact analysis
- System timeline investigation
- Suspicious process identification

## Network Forensics
- PCAP traffic analysis
- Malware traffic investigation
- Credential theft detection
- FTP traffic analysis
- IOC identification
- Suspicious domain analysis
- Attacker infrastructure tracing

---

# Tools Used

## Memory Analysis
- Volatility3
- FTK Imager
- Registry Viewer

## Network Analysis
- Wireshark
- NetworkMiner

---

# Key Findings

## Memory Investigation
- Identified running Windows processes and parent-child process relationships.
- Extracted user sessions, account hashes, and login activity from memory dumps.
- Analyzed Windows registry artifacts and system configuration data.
- Investigated suspicious system activity and forensic timelines.

## Network Investigation
- Investigated malicious PCAP traffic using Wireshark and NetworkMiner.
- Identified suspicious domains, attacker-related IP addresses, and malware communication patterns.
- Detected FTP credential exposure and suspicious external connections.
- Extracted indicators of compromise (IOCs) from captured network traffic.
